# Классификатор обращений

Небольшой учебный скрипт разбирает обращения из `messages.txt`, относит каждое к
одной из трёх категорий — `справка`, `жалоба` или `другое` — и печатает короткий
черновик ответа на русском языке.

Решение работает на правилах и не требует API-ключей или сторонних библиотек.
Сначала скрипт ищет признаки жалобы (например, «пропал», «очередь», «холодная»),
затем признаки информационного вопроса («как получить», «где»). Если признаки не
нашлись, обращение попадает в категорию `другое`. Для тем из задания подготовлены
контекстные ответы, а для новых сообщений предусмотрены универсальные черновики.

## Запуск

Нужен Python 3.9 или новее. Из корня репозитория выполните:

```bash
python3 classifier.py
```

Можно передать другой текстовый файл, в котором каждое обращение находится на
отдельной строке:

```bash
python3 classifier.py путь/к/messages.txt
```

На готовом наборе получаются категории: `справка`, `жалоба`, `другое`, `жалоба`,
`справка`. Рядом с каждой категорией выводится соответствующий черновик ответа.
